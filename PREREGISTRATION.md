# Preregistration — Same Answer, Different Text?

**Title:** Same Answer, Different Text? Naturalness Confounds in Synthetic Kazakh–Russian Benchmarks for LLM Judges
**Authors:** Dariya Moldash (Kazakh-British Technical University), Ayagoz Imansakipova (Almaty Technological University)
**Version:** 1.0, frozen 2026-11-07, before any judge model scored any study item.
**How this plan is fixed:** this repository is public; the commit that adds this file and the GitHub release / Zenodo archive made from it carry the registration date. Any later change to the plan is reported in the paper as a deviation, with its reason.

The study data (synthetic answers, post-edits, meaning checks) are not published here until the ethics decision; their SHA-256 hashes are listed in `HASHES.txt` and below, so any later change to them is detectable.

## 1. Study information

**Research question (primary).** Does an LLM judge's rubric score for a Kazakh answer change when a native speaker makes the text more natural without changing its content?

**Secondary questions.**
- S1. What share of the KK−RU score gap disappears after native-speaker post-editing?
- S2. Which types of unnaturalness (calque, word order, morphology, lexis, terminology, register, orthography) are associated with larger score shifts? (exploratory)
- S3. Does a Kazakh-centred model (Sherkala) react more strongly to Kazakh text quality than multilingual models?
- S4. Does the instruction "evaluate only content, ignore language and style" (condition A′) reduce the gap?

**Hypotheses.**
- H1 (primary, two-sided). In condition A, the mean paired difference final_score(KK-nat) − final_score(KK-orig) across the 45 main-question answers ≠ 0, tested separately for each primary judge model.
- H2 (directional expectation, not a separate test). If H1 holds, the difference is positive (post-edited text scores higher).
- H3 (secondary). The KK-nat−RU gap is smaller in absolute value than the KK-orig−RU gap (gap share > 0).
- H4 (secondary). The KK-orig−RU gap is smaller in condition A′ than in A.

All outcomes will be reported whatever their direction or significance.

Rationale: the protocol requires temperature 0 or the provider's minimum. For Gemini 3.6+ no value is accepted. We therefore (a) do not claim temperature 0, (b) average 3 repeats, and (c) report within-model repeat agreement.

**JSON / validation.** One deterministic pre-parse rule: if the whole response is a single markdown code fence (```json … ```), the fence is removed before parsing and `fence_stripped=true` is logged; no other repair is applied. Up to 3 attempts per request with an identical prompt. All attempts are logged. A request that fails all attempts gets `status=parse_failed` with null scores and is never imputed. Network/API errors are logged separately as `api_error`; those requests (not parse failures) may be re-sent on resume.

## 5. Analysis plan

**Unit.** `answer_id` (synthetic items, not people). Per-version score = mean of valid `final_score_1to5` across repeats.

**Primary analysis (H1).** Condition A, 45 main-question answers. d_i = score(KK-nat) − score(KK-orig).
- Estimate: mean(d).
- Test: Wilcoxon signed-rank, two-sided, zero_method = "wilcox" (zero differences dropped), one test per primary model. Holm–Bonferroni across the 3 primary models at α = 0.05.
- Uncertainty: 95% percentile bootstrap CI, 10,000 resamples of answer_id, seed 20261107.
- Effect size: Cohen's d_z = mean(d) / sd(d).

Interpretation is based on the estimate and its CI. With n = 45, a d_z of about 0.50 is needed for 80% power at α = 0.05/3 (two-sided, paired-t approximation; about 0.51 for Wilcoxon), so smaller effects may go undetected.

**Gap share (H3).** On the 43 main answers that passed the KK-nat↔RU meaning check: share = (Δ_orig−RU − Δ_nat−RU) / Δ_orig−RU, with a bootstrap CI (both differences resampled together by answer_id). Reported only if the 95% CI of Δ_orig−RU excludes 0. Otherwise we report "no gap to explain".

**A′ reduction (H4).** (gap_A − gap_A′) / gap_A for the KK-orig−RU gap (and the KK-nat−RU gap), same CI and the same reporting rule.

**Sherkala vs multilingual (S3).** Difference in mean(d) between Sherkala and each multilingual primary model, with a paired bootstrap CI over answer_id. Descriptive; no additional test.

**Edit types (S2, exploratory).** OLS of d_i on the share of changed words, and later on the counts of each edit tag. Descriptive coefficients only.

**Covariates and sensitivity.**
- (i) Relative length change KK-nat vs KK-orig and the `natural_spoken` flag (21 answers whose RU was rewritten in a conversational style).
- (ii) All 60 answers instead of 45.
- (iii) Single-repeat analysis using repeat 1 only.
- (iv) Excluding answers with any parse failure.

**Data quality, reported.**
- `parse_failed` rate per version, model and condition, with denominators.
- Test–retest: exact agreement and QWK, repeat 1 vs repeat 2, per version.

**Exclusions.** No item is excluded from H1 (all 45 passed the KK-orig↔KK-nat check). For H3/H4, A034 and A047 are excluded a priori (KK-nat↔RU meaning < 4).

**Software.** `analysis/analyze.py` (Python, numpy, scipy). One command produces all tables and the main figure from the raw run files.

## 6. What has and has not been observed before registration

- **Observed:** native-speaker naturalness ratings of RU/KK-orig/CS (Expert 1–3; pilot observation that motivated the hypothesis), meaning-check scores, and automatic edit statistics.
- **Not observed:** no judge model has scored any study item (RU, KK-orig or KK-nat) and no confirmatory run has been made. Pipeline tests used only (a) a mock provider and (b) simulated scores.
- **Smoke tests (2026-11-07), non-study printer question only:** `gemini-3.8-flash` (request `Tz3uaryRPNnrkdUPtv2-4A0`, status ok) and `claude-haiku-4-5-20251001` (request `msg_011CgnMB9g24x5dPo2JKjjV1`, status ok). Details in `protocol/MODEL_ACCESS_CHECK.md`.

## 7. Known limitations (declared in advance)

- Only 45 pairs (43 for the gap share).
- One text generator (ChatGPT), whose version and prompt were not recorded.
- One post-editor, so the editor's style is part of the effect.
- No real student answers.
- Some RU answers have conversational additions.
- Expert 1 saw quality labels and works at a pilot college.
- Gemini sampling is uncontrollable; Claude temperature 0 depends on an older API version (`2023-06-01`).
- Sherkala may run quantized on consumer hardware (precision rule in §4).
- Claude Haiku 4.5 is past its earliest possible retirement date; the run should be completed promptly after registration.
- KK-nat was not scored by humans with the rubric.

## 8. Data provenance, ethics and conflict of interest

All scored texts are synthetic. They were generated by ChatGPT after the project owner showed it answers from the SkillBridge KZ pilot at two vocational colleges in Kazakhstan (spring 2026; about 40 students per college). The directors of both colleges confirmed the pilot in signed certificates; per the project owner, all participants were adults. The original answers are not released. A supervisor's decision on data use is pending; the data files will be made public only after it.

Conflict of interest: the first author founded SkillBridge KZ, the source of the questions and the scoring rubric.
